# Reinstalling or changing your system

From your VPS's service page in the [client area](https://clients.lklcloud.fr), open **Reinstall OS**.

:::warning
All data on the server is erased. A "before operation" backup is created automatically before starting.
:::

1. Choose the distribution (Debian or Ubuntu).
2. A new root password is generated and shown once — write it down immediately.
3. Your saved SSH keys are re-injected automatically via cloud-init.

This takes about 3 to 5 minutes. The service restarts automatically once done.
