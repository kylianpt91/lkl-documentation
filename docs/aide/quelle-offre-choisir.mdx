# Quelle offre choisir ?

## Vous voulez un serveur pour vos propres projets (API, application, jeux, expérimentation)

→ **VPS Linux** : accès root complet, vous installez ce que vous voulez. Demande un peu plus de connaissances techniques (ligne de commande). Voir [Premiers pas avec votre VPS](/vps-linux/premiers-pas).

## Vous voulez héberger un site internet (WordPress, boutique, site vitrine)

:::info Bientôt disponible
L'hébergement web n'est pas encore ouvert à la commande en libre-service.
:::

Une fois disponible : **Hébergement web** avec le panel Plesk, installation simple, SSL gratuit, pas de ligne de commande nécessaire. Voir [Débuter avec Plesk](/web/plesk-debuter).

Si vous avez besoin d'installer des logiciels spécifiques, de plusieurs applications indépendantes ou d'un contrôle total du serveur, un **VPS** est plus adapté et disponible dès maintenant.

## Vous voulez héberger un bot Discord (Node.js ou Python)

:::info Bientôt disponible
Les bots Discord ne sont pas encore ouverts à la commande en libre-service.
:::

Une fois disponible : **Bots Discord** via le panel Pterodactyl, upload de votre code, démarrage en un clic, pas de gestion serveur. Voir [Déployer votre bot](/bots-discord/demarrer).

## Vous voulez juste un nom de domaine

:::info Bientôt disponible
L'enregistrement de nom de domaine n'est pas encore ouvert à la commande en libre-service.
:::

Une fois disponible : **Noms de domaine**, avec ou sans hébergement associé. Voir [Gérer son nom de domaine](/domaines/premiers-pas).

## Vous hésitez encore ?

Contactez-nous à [support@lklcloud.fr](mailto:support@lklcloud.fr) en décrivant votre projet, on vous oriente vers la bonne offre.
