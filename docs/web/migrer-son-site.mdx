# Migrer un site depuis un autre hébergeur

:::info Bientôt disponible
Cette page suppose un hébergement web actif chez LKL Cloud, pas encore ouvert à la commande (voir [Débuter avec Plesk](/web/plesk-debuter)).
:::

Une fois le service disponible, la migration suivra ces grandes étapes :

1. **Export chez l'ancien hébergeur** : fichiers via FTP/SFTP ou archive complète, dump SQL de la base de données.
2. **Création du site sur LKL Cloud** : ajout du domaine dans Plesk, en utilisant le sous-domaine temporaire fourni tant que le domaine pointe encore vers l'ancien hébergeur.
3. **Import des fichiers et de la base**, puis mise à jour des identifiants de connexion dans la configuration du site.
4. **Tests via le sous-domaine temporaire**, avant de couper le DNS de l'ancien hébergeur.
5. **Bascule du domaine** une fois les tests concluants.

## Besoin d'aide pour planifier une migration ?

Écrivez-nous à [support@lklcloud.fr](mailto:support@lklcloud.fr) en précisant votre CMS (WordPress, etc.) et la taille approximative de votre site, nous reviendrons vers vous dès l'ouverture de ce service.
