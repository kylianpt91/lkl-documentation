# Migrer un site depuis un autre hébergeur

## 1. Préparer l'export chez l'ancien hébergeur

- **Fichiers** : téléchargez l'intégralité du site via FTP/SFTP, ou générez une archive complète si votre ancien panel le propose.
- **Base de données** : exportez un dump SQL complet (souvent via phpMyAdmin → **Exporter**, ou une commande `mysqldump`).

## 2. Créer le site sur LKL Cloud

Depuis Plesk, ajoutez votre domaine comme décrit dans [Débuter avec Plesk](/web/plesk-debuter). Tant que le domaine pointe encore vers l'ancien hébergeur, utilisez le sous-domaine temporaire fourni pour travailler sans coupure.

## 3. Importer vos fichiers et votre base

- Déposez vos fichiers via le gestionnaire de fichiers Plesk ou en FTP/SFTP.
- Créez une base de données (**Bases de données** → **Ajouter**) et importez votre dump SQL.
- Mettez à jour les identifiants de connexion à la base dans la configuration de votre site (souvent un fichier `wp-config.php`, `.env` ou équivalent selon votre CMS).

## 4. Tester avant de basculer le DNS

Utilisez le sous-domaine temporaire (ou modifiez temporairement votre fichier `hosts` local) pour vérifier que le site fonctionne correctement chez LKL Cloud **avant** de couper le DNS de l'ancien hébergeur.

## 5. Basculer le domaine

Une fois les tests concluants :

- Si votre domaine est déjà chez LKL Cloud, modifiez simplement l'enregistrement **A** pour pointer vers votre nouvel hébergement (voir [Gérer son nom de domaine](/domaines/premiers-pas)).
- Sinon, transférez le domaine ou modifiez les enregistrements DNS chez votre registrar actuel.

Comptez jusqu'à 24 h pour une propagation complète — gardez l'ancien hébergement actif pendant ce délai, le temps que tous les visiteurs basculent.

## Besoin d'aide pour la migration ?

Écrivez-nous à [support@lklcloud.fr](mailto:support@lklcloud.fr) en précisant votre CMS (WordPress, etc.) et la taille approximative de votre site.
