# Débuter avec votre hébergement web

Votre offre d'hébergement web repose sur le panel **Plesk**, accessible depuis la fiche de votre service dans l'[espace client](https://clients.lklcloud.fr) (bouton **Ouvrir Plesk**).

## Ajouter votre site

1. Dans Plesk, ouvrez **Sites Web & Domaines**.
2. Ajoutez votre nom de domaine (ou utilisez le sous-domaine temporaire fourni si votre domaine n'est pas encore actif).
3. Déposez vos fichiers via le **gestionnaire de fichiers** intégré ou en FTP/SFTP (identifiants dans **Comptes FTP**).

## Certificat SSL

Un certificat **Let's Encrypt** gratuit peut être activé en un clic depuis l'onglet **SSL/TLS** de votre domaine — le renouvellement est automatique.

## Bases de données

**Bases de données** → **Ajouter une base de données**. Le nombre de bases disponibles dépend de votre offre (voir le récapitulatif sur la fiche de votre service).

## Sauvegardes

Des sauvegardes automatiques quotidiennes sont conservées 7 jours (30 jours avec l'option « Sauvegardes étendues »). Restauration possible directement depuis Plesk, onglet **Sauvegarde/Restauration**.
