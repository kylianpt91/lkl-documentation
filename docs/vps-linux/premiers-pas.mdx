# Premiers pas avec votre VPS Linux

Après le paiement de votre commande, votre VPS est déployé automatiquement (comptez quelques minutes). Vous recevez un e-mail dès qu'il est prêt.

## Retrouver les informations de connexion

Depuis l'[espace client](https://clients.lklcloud.fr), ouvrez **Mes services** → votre VPS. Vous y trouverez :

- L'adresse IP de votre serveur
- Le système installé (Debian ou Ubuntu selon votre choix à la commande)
- Le nombre de vCores, la RAM et le disque de votre offre

## Se connecter en SSH

Si vous avez ajouté une clé publique dans **Paramètres → Clés SSH** *avant* de commander, elle est injectée automatiquement :

```bash
ssh root@VOTRE_IP
```

Sinon, un mot de passe root est généré et affiché une seule fois sur la fiche du service (zone floutée, cliquez pour révéler ou copier). Changez-le dès votre première connexion.

<div className="admonition admonition-note">
Ajouter une clé SSH <em>après</em> la création du service ne la met pas automatiquement sur un VPS déjà actif : ouvrez un ticket pour l'ajouter manuellement en attendant.
</div>

## Console de secours

Si le SSH ne répond pas, la fiche de votre service propose une **console** : vous tapez une commande, vous validez, le résultat s'affiche après quelques secondes à une minute. Ce n'est pas un terminal interactif comme SSH (pas d'édition de fichier en direct, une seule commande à la fois).

## Sauvegardes

Il n'y a pas encore de sauvegarde automatique périodique : chaque sauvegarde est déclenchée manuellement, depuis l'onglet **Sauvegardes** de la fiche du service.

- **1 €** débité à la demande, automatiquement remboursé si la sauvegarde échoue pour une raison technique.
- Prête en quelques minutes.
- Restauration gratuite, en un clic.

## Suivre la consommation

L'onglet **Utilisation** affiche l'évolution réelle du CPU, de la RAM et du réseau sur les 30 derniers jours (mesures remontées chaque minute, pas une simulation).

## Actions disponibles depuis l'espace client

Depuis la fiche de votre VPS :

- **Démarrer / Redémarrer / Arrêter**
- **Changer d'offre** (redimensionne réellement vCPU/RAM/disque)
- **Cloner** le service en une nouvelle instance
