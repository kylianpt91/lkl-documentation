# Réinstaller ou changer de système

Depuis la fiche de votre VPS dans l'[espace client](https://clients.lklcloud.fr), ouvrez **Réinstaller l'OS**.

:::warning
Toutes les données du serveur sont effacées. Une sauvegarde « avant opération » est créée automatiquement avant le lancement.
:::

1. Choisissez la distribution (Debian ou Ubuntu).
2. Un nouveau mot de passe root est généré et affiché une seule fois — notez-le immédiatement.
3. Vos clés SSH enregistrées sont réinjectées automatiquement via cloud-init.

Comptez 3 à 5 minutes. Le service redémarre automatiquement une fois l'opération terminée.
