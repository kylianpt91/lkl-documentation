# Réinstaller ou changer de système

La réinstallation du système en libre-service depuis l'espace client n'est **pas encore disponible**.

Si vous avez besoin de repartir d'un système propre sur votre VPS, [ouvrez un ticket](https://clients.lklcloud.fr/support/nouveau) avec :

- le service concerné,
- la distribution souhaitée (Debian ou Ubuntu).

Notre équipe s'en charge manuellement.

:::warning Toutes les données seront effacées
Comme pour toute réinstallation, le disque est intégralement remplacé. Si vous avez des données à conserver, faites une [sauvegarde](/vps-linux/premiers-pas#sauvegardes) avant d'ouvrir le ticket.
:::
