# Moyens de paiement

## Carte bancaire

Paiement sécurisé par carte, traité par Stripe. Le service est livré automatiquement dès la confirmation du paiement.

## PayPal

Payez directement avec votre compte PayPal depuis la page de votre facture.

## Virement bancaire

Sur la page de votre facture, choisissez **Payer par virement**. Vous obtenez :

- L'IBAN et le BIC de LKL Cloud
- Le montant exact à virer
- Une **référence unique** à indiquer impérativement dans le libellé du virement

:::danger Référence obligatoire
Sans cette référence dans le libellé, votre virement ne peut pas être identifié automatiquement et votre service ne sera pas livré tout de suite. Un rapprochement manuel par notre équipe reste possible mais prend plus de temps.
:::

Une fois le virement fait, cliquez sur **J'ai fait le virement : vérifier maintenant** pour une vérification immédiate, plutôt que d'attendre la vérification automatique (toutes les 15 minutes).

- **Virement instantané** : facture réglée en quelques minutes.
- **Virement classique** : sous 1 à 2 jours ouvrés.
