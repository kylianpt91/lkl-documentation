# Activer la double authentification

Nous vous recommandons fortement d'activer la 2FA sur votre compte, surtout s'il gère plusieurs services.

1. Connectez-vous à l'[espace client](https://clients.lklcloud.fr).
2. Ouvrez **Compte** → **Sécurité**.
3. Activez la double authentification et scannez le QR code avec une application comme Google Authenticator, Authy ou 1Password.
4. Conservez précieusement les codes de secours affichés — ils permettent de récupérer l'accès si vous perdez votre téléphone.

Une fois activée, un code à 6 chiffres vous sera demandé à chaque connexion, en plus de votre mot de passe.

## Se connecter avec Google

Vous pouvez aussi vous connecter directement avec votre compte Google, sans mot de passe séparé à retenir, depuis le bouton **Continuer avec Google** sur la page de connexion.
