# À propos de LKL Cloud

## Depuis quand LKL Cloud existe-t-il ?

LKL Cloud est porté par une association déclarée depuis le **28 décembre 2025** (publication au Journal Officiel des associations le 6 janvier 2026).

## Êtes-vous déclarés ?

Oui. LKL Cloud est une association loi 1901 déclarée :

- **SIRET** : 999 237 175 00016
- **RNA** : W913016294
- **Siège** : Villiers-le-Bâcle (91190)

## Avez-vous votre propre infrastructure ?

Oui, LKL Cloud exploite son propre serveur dédié, sans reposer sur un hébergeur cloud tiers pour la partie hébergement — vos services tournent directement sur notre infrastructure.
